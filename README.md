🎬 Netflix Clone (React + Express + PostgreSQL)

A Netflix-style web application built with React, Express, and PostgreSQL.
The app includes Login, Sign Up, and Home pages with secure authentication and movie data fetched from the TMDB API.

✨ Features

1)User Sign Up and Login with PostgreSQL database

2)Secure credential storage

3)Express backend for authentication and API handling

4)Home page displaying trending movies from TMDB

5)Protected routes after authentication

6)Logout functionality

7)Responsive Netflix-style UI

React
CSS

Backend
Node.js
